PORTFOLIO — GITHUB PAGES — QUATTRO TAPPE INTERATTIVE

Ogni progetto mostra una sola schermata alla volta.
Fase 1: Presentazione > Scopri il problema
Fase 2: Problema > Avanti
Fase 3: Soluzione > Clicca l’immagine per passare all'anteprima successiva; ⤢ ingrandisce la schermata; Avanti porta all’utilità.
Fase 4: Utilità > Torna al portfolio.
Non ci sono pulsanti Indietro, barre di avanzamento o inviti persistenti a cliccare.
Le immagini hanno object-fit:contain e possono essere ingrandite per leggere i dettagli.
Se una schermata è più alta del display, si può scorrere verticalmente dentro la tappa.

PUBBLICAZIONE: carica tutti i file nella radice di un repository pubblico GitHub e abilita Settings > Pages > Deploy from a branch > main / (root).
I contatti usano mailto:, senza backend.
I grafici dimostrativi non rappresentano dati reali.
